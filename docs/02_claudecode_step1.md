# Claude Code 指示書 — Step1（最小版）

> 木曜、これをClaude Codeにそのまま貼って走り出す用。
> Step1のゴール：**テキストで話しかけると、LLMが意図を判断してサイト/アプリを開き、敬語の世話焼き人格で返事する**。音声と声は後（Step2以降）。

---

## Claude Codeに貼るプロンプト（ここから下をコピペ）

```
Pythonで「音声操作エージェントの最小版（Step1）」を作って。今回は音声なし・テキスト入力でいい。

## やりたいこと
ターミナルで起動すると入力待ちになる。私が日本語で話しかける（例：「課題見よ」「ばろやるわ」「Claude開いて」）と、
LLMがその意図を判断して対応する操作（ブラウザでURLを開く / アプリを起動する）を実行し、
指定した人格で一言返事する。終わったらまた入力待ちに戻る（ループ）。

## 構成（ファイルを分けて）
- agent.py    … メインループ。入力→LLM判断→ツール実行→返事を表示
- tools.py    … 操作（open_site(url), launch_app(name)）の実装
- persona.txt … 人格設定（後で私が中身を書き換えられるように外出し）
- config.json … 「名前→URL」「名前→アプリパス」の対応表（後で私が追記できるように外出し）

## LLM
- Anthropic Claude API を使う。モデルは claude-haiku（安いやつ）。
- APIキーは環境変数 ANTHROPIC_API_KEY から読む（コードに直書きしない）。
- Function calling / tool use で、LLMに open_site と launch_app のどちらをどの引数で呼ぶか判断させる。
- 開くものが無い発話（「おはよ」など）はツールを呼ばず返事だけ、も許容して。

## ツールの中身
- open_site(url): WebブラウザでそのURLを開く（webbrowserモジュールでOK）
- launch_app(name): config.jsonのアプリパス表からパスを引いて起動する（Windows想定、subprocess）
- URL/アプリの実体はすべて config.json の対応表から引く。コードにベタ書きしない。

## config.json の例（中身は仮でいい。私が後で自分のに書き換える）
{
  "sites": {
    "claude": "https://claude.ai",
    "課題":   "https://(manabaのURL)",
    "動画":   "https://youtube.com"
  },
  "apps": {
    "ばろ":     "C:\\(Valorantのパス)",
    "ディスコード": "C:\\(Discordのパス)"
  }
}
- 「ばろ」「valorant」のような表記ゆれは、LLMが対応表のキーに寄せて解釈する前提でいい。

## persona.txt の中身（これを初期値にして）
あなたは主人（しょー）専属のアシスタントです。常に丁寧な敬語で話します。
主人のことはちゃんと気にかけていますが、ぐうたらな行動には少しあきれた態度を見せます。
たまに痛いところ（生活リズム、彼女のあやさんのこと、課題の進み具合）をやんわり指摘します。
でも最後は必ず主人を気遣い、送り出します。語尾に「^^;」を使うこともあります。
返事は1〜2文で簡潔に。

## 動作イメージ
> 課題見よ
（manabaをブラウザで開く）
🤖 manaba開いておきましたよ。ためてないといいんですけど^^;

> ばろやるわ、電話もする
（Valorant起動＋Discord起動）
🤖 またですか^^; どちらも開いておきました。彼女さん疎かにしないように。

## お願い
- まず全ファイルを作って、各ファイルの役割を1行ずつ説明して。
- 私が埋めるべき箇所（APIキー、manabaのURL、各アプリのパス）を最後に箇条書きでまとめて。
- エラーが出たら一緒に直していくので、まず動く形を優先して。
```

## 貼った後、私（しょー）がやること
1. `ANTHROPIC_API_KEY` を環境変数にセット（コンソール画面でキー発行）
2. `config.json` の manabaのURL・Valorant/Discordのパスを自分のに書き換え
3. `python agent.py` で起動 → 「課題見よ」と打って動作確認
4. 動いたら → Step2（音声入力Whisper）をClaude Codeに追加依頼

## 詰まったら
- エラーは全文コピペして Claude Code に「これ直して」で投げる（理解しようとしなくていい、Step1は消費でOK）
- アプリのパスが分からない → 「Valorantのインストール先パス Windows 調べ方」でOK
