# ADR-0035 音声入力（Step2）— マイク→VAD→Whisper(ローカル)→core→読み上げ

- 状態: 採用（2026-06-11）。当初ロードマップの最終ピース「声だけで完結」。

## 課題
これまで入力はテキスト（web.py）のみ。本来のビジョン「帰宅後、声だけでPC操作・予定確認が完結」には音声入力が要る。

## 判断
- **新しい"耳口" `voice.py` を core.run_turn の上に作る**（web.py / agent.py と同じ中核を共有。耳と口を足しただけ）。
- パイプライン: sounddevice(マイク) → webrtcvad(発話区間検出) → **faster-whisper(ローカルSTT)** → core.run_turn
  → テキスト返答表示 ＋ speak.py(VOICEVOX=つむぎ/未起動はsay)で読み上げ。
- **STTはローカル＝API課金ゼロ**。脳(haiku)のコストは従来通り＝音声化でコストは増えない（ADR-0032/0033の予算を維持）。
- **エコー対策**: 読み上げ(speak block=True)中はマイクを開かない。録音→STT→core→発話→録音… と直列にして自分の声で誤起動しない。
- **ノイズ/幻聴除去**: 短すぎる発話・Whisperの定番幻聴（「ご視聴ありがとうございました」等）は無視。
- **音声コマンド**: 「終了/バイバイ」で停止、「リセット」で会話記憶クリア。
- L1（ターン制：話す→無音で確定→処理→返答）。ストリーミング/バージイン等のレイテンシ最適化は将来。

## 実装
- voice.py（VAD録音ループ + faster-whisper + core + speak）。env: WHISPER_MODEL(既定small)/VAD_AGGRESSIVENESS/SILENCE_MS。
- requirements: faster-whisper, sounddevice, webrtcvad, numpy 追加。
- 検証(2026-06-11): VOICEVOX生成wav→faster-whisper(small)で「明日の予定を教えて」を一字一句正確に文字起こし
  (モデル読込~20s/発話2.6s)。STT→core連鎖で明日のGoogle＋ローカル統合予定を読む所まで実機確認。
  実マイク録音(VAD)はユーザーが自分のターミナルで `python voice.py` し発話＋マイク許可してE2E（マイク検出済: しょすけ Microphone）。

## Update（2026-06-11）: レイテンシ最適化（「返答が遅い」を半減）
実測ボトルネック: VOICEVOX合成が長文5.7s（最大）/ Whisper small 2.4s。対策:
- **TTSを文ごとにストリーミング**（speak._voicevox_speak）: 最初の一文を合成したら即再生し、残りは裏スレッドで合成。
  → 出だしまで **5.7s→1.8s**（体感の頭が劇的に速い）。say経路は従来通りフォールバック。
- **Whisper 既定を small→base**: 0.48s（small 2.37sの約5倍速）。精度は僅かに落ちるが短い命令は実用十分
  （気になれば env WHISPER_MODEL=small）。
- **無音待ち SILENCE_MS 800→600ms**: 発話終わりの間を短縮。
- 残: LLM多段（起動+配置等で2-3コール）が次の塊。フィラー発話で隠す/ストリーミングSTTは将来。

## Update2（2026-06-11・Fableレビュー）: 体感速度＋音声UXの総点検
- **フィラー相槌**: LLMが0.9秒で返らなければ、起動時に合成済みの相槌（はい。/ええと。等）を即再生
  → 無音の待ちが消える（体感が「考えてから話す人」になる）。VOICEVOX未起動なら相槌なしで動作。
- **ウォームアップ**: 起動時に Whisper と VOICEVOX を空回しし、初回ターンの遅延を排除。
- **音声モードは天気タブを開かない**（tools.SHOW_WEATHER_PAGE=False。読み上げが配信手段・タブ開きっぱ問題の根治）。
  web UI は従来通り開く（見せる配信）。
- **一時タブの後片付け＋画面復帰**: voice.py も web 同様、前ターンの ephemeral（web_search等）を次の発話の頭で
  自動クローズし、タブを開く前に前面だったアプリへ activate で画面を戻す（ブラウザ自身が前面だった場合は戻さない）。
- **返答の短文化**: persona に Voice mode 指示を連結（1-2文・リスト/URL禁止）→ TTSも速い。
  ※音声セッションは専用のキャッシュプレフィックスになる（コスト挙動は同じ）。
- **終了語の誤爆修正**: 「終了」等は完全一致のみ（「ゲーム終了して」で音声モードが落ちない）。
  「おやすみ」は終了語から外し、人格の挨拶（明日の予定にひと言）に委ねる。
- 既知の保留: 別デスクトップ(Spaces)間のウィンドウ移動はmacOS APIが無く茨の道 → Windows版の挙動を見て判断（Issue化）。
  バージイン（読み上げ中の割り込み）とストリーミングSTTは将来。
