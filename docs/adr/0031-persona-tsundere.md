# ADR-0031 人格の確立（ちょい毒舌・世話焼き・マスター大好きな女性ロボ）

- 状態: 採用（2026-06-11）。機能がほぼ揃い、最後の差別化＝人格をユーザーの好みで確定。

## 課題
機能（操作・記憶・配信）は揃ったが、人格が generic な「丁寧な世話焼き執事」止まりで、相棒としての魅力が薄い。
加えて、システムプロンプトに機能ルール（鉄則・捏造ガード・ツール説明）が積み上がり、人格が埋もれて
無味乾燥になる／ツール結果（「Discord を左半分に配置しました」等）が素のまま漏れる、という劣化があった。

## 判断（ユーザー決定 2026-06-11）
- **キャラ**：女性型ロボット。ちょい毒舌でお小言が多いが、根はマスターを信頼し大好き。毒舌は否定でなく
  「おせっかい・心配の裏返し」。先回りして世話を焼き、最後はちゃんと味方（ツンの奥にデレ）。呼称＝マスター。
- **persona.txt 全面改稿**：人格を最上段に、**お手本会話（few-shot）**で声を例示（説明より一貫性が出る）。
  記憶を織り込む・捏造防止などの機能ルールは保持。
- **脱ロボ化**：ツール結果を素でコピーせず必ず人格で言い換える指示＋ core 側で「無言フォールバック時に
  ツール結果を人格で一言に言い換える」`_rephrase` を追加（実モードのみ。dry_run は検証用に素のまま）。
- **声**：VOICEVOX 既定話者を 3(ずんだもん) → **6(四国めたん ツンツン)** に。ちょい毒舌の女性人格に合わせる
  （env VOICEVOX_SPEAKER で上書き可。エンジン未起動時は say にフォールバックなので可聴検証は実機起動後）。
- profile の呼称を「主人」→「マスター」に。

## 影響
- persona.txt 改稿 / speak.py 既定話者変更 / core.py に `_rephrase`（無言時の人格言い換え） / profile.example.json 呼称更新。
- 検証(2026-06-11・実機): 挨拶「ちゃんと起きられたんですね、えらいじゃないですか」/ 天気「傘要りません…でも折り畳み傘入れておくんですよ、また失くさないで」/ 操作「Chromeは左に置いておきました。右側は何を開きます？」/ 既起動「もう開いてますって、何回言わせるんですか」。会話・情報・操作・お断りで人格が一貫、ロボ口調の漏れも解消。
