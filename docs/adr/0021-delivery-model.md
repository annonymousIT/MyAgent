# ADR-0021 情報配信モデル（ephemeral / persistent ＋ 自動クローズ）

- 状態: 採用（2026-06-11）。[ADR-0018](0018-resourceful-within-pc.md)（届ける）の具体化。

## 課題
情報をどう届けるか。「開くだけ」だと中身が伝わらず、「開きっぱなし」だと画面が散らかる。

## 判断（配信を2種に分ける）
- **ephemeral（一時的に知りたい：天気・株・調べもの）**
  - ウィンドウを**開いて見せる** ＋ 内容を**要約して伝える**（テキスト → Step3で音声読み上げ）。
  - **用が済んだら自動でクローズ**する。← 「見せて・伝えて・後片付け」まで全うする。
- **persistent（見る・流す・作業：動画・音楽・ブラウジング）**
  - 開いて、（必要なら）モニタに配置して、**残す**。

## 自動クローズの実現
- エージェントが「**自分が開いた窓と、それが ephemeral か**」を覚えている必要がある → **[Step5 短期記憶](../issues_plan.md)（開いた窓の台帳）が前提**。
- クローズ手段：Chrome AppleScript `close (tab whose URL contains …)` / `quit application "X"`（タブグループ保留[#17]と違い、close 自体は可能）。
- **エージェント自身が ephemeral として開いた窓は無確認でクローズしてよい**（[ADR-0019](0019-permission-model.md) の終了確認は“ユーザーの既存窓・未保存作業”向け。一時窓は対象外）。

## 影響
- Step5 に「開いた窓の台帳（URL/アプリ名・ephemeralフラグ・いつ開いたか）」を持たせる。
- B（取得＋要約）と close 能力を実装。読み上げは Step3。
- ウィンドウ配置（モニタ/サイズ/移動）は別トラック（A+D, Issue化）。
