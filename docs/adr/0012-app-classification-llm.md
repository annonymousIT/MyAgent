# ADR-0012 アプリ分類・呼び名の LLM 自動生成

- 状態: 採用（2026-06-11）

## 課題
OS スキャンで得られるのはアプリ名（例 `Discord.app`）だけ。カテゴリも、日本語の呼び名・略語も付いていない。これを人手で全部書くのはフレームワーク化の妨げ。

## 選択肢
- A. 手動キュレーション辞書
- B. LLM 自動生成
- C. ハイブリッド（主要は辞書、未知は LLM）

## 判断
**B（LLM 自動生成）＋手動修正**。セットアップ時にスキャンしたアプリ一覧を Claude に渡し、カテゴリ＋日本語の呼び名・略語を生成して `config.auto.json` に書き出す。誤りは `config.user.json` で上書き。

## 理由
- 既に Claude を使っており、**追加の基盤が要らない**。
- 任意のアプリに汎用で効き、**略語も同時に得られる**（[ADR-0013](0013-abbreviation-handling.md) の呼び名リストを兼ねる）。
- 誤分類は手動層（[ADR-0011](0011-framework-two-layer-config.md)）で安全に補正できる。

## 影響
- セットアップ時に 1 回 API 課金（軽微・一度きり）。
- 生成物の品質は user 層で担保。
- 再スキャンで auto 層のみ作り直し、user 層の補正は保持。
