# ADR-0038 音声の起動方式 — 常時録音をやめ、明示トリガーにする

- 状態: 提案中（2026-06-11）。ユーザー判断待ち。現状の実装と設計意図のズレを是正する。

## 課題
現状 `voice.py` は **常時録音（VAD で発話区間を検出し、拾った言葉をそのまま実行）**。
ウェイクワードも Push-to-Talk も無い。よって**ゲーム中・Discord通話中・独り言を誤って拾って誤爆する**。
設計メモ（[01_design_memo] §9-(1)）では当初から「Push to Talk を基本にする」と決めていた＝**実装が設計意図とズレている**。

## 判断（方針・選択肢）
「常に意思を持って起動する」を原則にする（[ADR-0019] 自律性の制限と同じ思想）。候補：

1. **クリック/長押しで話す（orbトリガー）** … [ADR-0036] の orb を発話ボタンにする。押した時だけ1発聞く。
   → ゲーム中も安全（押さなければ起動しない）。視覚的に状態が分かる。orb と統合できて筋が良い。【第一候補】
2. **グローバルホットキー（Push-to-Talk）** … 特定キー押下中だけ録音。ゲームと衝突しないキー選定が要る。
3. **ウェイクワード** … 「ねえ」等を軽量ローカル判定で前段に置く。誤起動が残る・実装重い。常時マイクは変わらず。

いずれも「**常時実行をやめる**」のが核。`MYAGENT_VOICE`/設定で音声経路を明示的にON/OFFできるようにする。

## 影響（実装時）
- `voice.py`: 常時ループ → トリガー駆動へ。orb（`overlay.py`）と連携する場合はプロセス間連携が要る。
- 当面の安全策: 音声モードは手動起動（`python voice.py`）のみで、自動常駐しない（[やらないこと]＝起動時自動常駐の封印）。

## Update（2026-06-11）: 仮決定＝ウェイクワード「やっほーエージェント」
ユーザー判断（2026-06-11）で、まずは**ソフトウェア・ウェイクワード**を採用（候補3の簡易版）。
- `voice.py` は VAD で常時録音するが、**`やっほーエージェント` を含む発話だけ反応**する。
  含まない発話（ゲーム中の声・通話・独り言）は無視＝誤爆しない。
- ウェイク＋コマンドを一息で言える（「やっほーエージェント、Discord開いて」）。呼びかけのみなら「はい、マスター？」と返す。
- 一度起動したら `AWAKE_WINDOW`(既定20秒) は呼びかけ不要で連続会話。対話のたびに延長。
- 表記ゆれ（やっほー/ヤッホー/やっほ）を正規表現で吸収。`WAKE_PHRASE`/`AWAKE_WINDOW_SEC` で調整可。
- 検証（2026-06-11）: ウェイク有→コマンド抽出、ウェイク無→無視、部分一致（やっほーのみ）→無視 を確認。
- 残課題: 常時マイクは変わらない（プライバシ/リソース）。本命は **orb click-to-talk**（[#35]）で常時録音自体をやめる。

## Update2（2026-06-12）: orb を司令塔に＝PowerShell 卒業
PowerShell で `python voice.py` を手打ちする UX を廃止（"スクリプトを動かす"感がコンセプトを壊す）。
- **orb 左クリック＝聴取（ウェイクワード待ち受け）の ON/OFF**。ON 中は orb が明るく速く脈打つ＝状態が一目で分かる。
  押さなければ起動しない＝ゲーム中も安全（[ADR-0019]）。
- **右クリック＝メニュー（設定 / 終了）**。
- 聴取 ON で overlay.py が voice.py を **小さなコンソール付き子プロセス**で起動（認識テキスト/コストが見える）。
  OFF で terminate。子が自分で終了（「終了」発話）したら orb が検知して OFF 表示へ戻す。
- 起動時に VOICEVOX(50021) が落ちていれば config から見つけて裏で起動（best-effort）。
- **自動常駐**: スタートアップに orb（pythonw＝黒窓なし）の .lnk を置く（`scripts/install_shortcuts.ps1`）。
  ログイン時に orb は出るが、**聴取はクリックするまで始まらない**＝勝手に聴かない（[ADR-0019] 自律性の制限）。

## Update3（2026-06-12）: PTT を既定に＋ウェイクワードは選択式
実走ログで、音楽/ゲーム等のうるさい環境では常時録音＋ウェイクワードが破綻すると判明
（マイクが音楽を拾い Whisper が幻聴／ウェイクワードを聞き逃す）。対策として **2モード切替**にした：
- **PTT（既定・推奨）**: 右Ctrl（`ptt_key`）を押している間だけ録音。環境音を一切拾わない＝うるさくても確実。
  ウェイクワード不要。`GetAsyncKeyState` でキー押下を見るだけ（追加依存なし・Windows）。
- **ウェイクワード**: 従来の「やっほーエージェント」。静かな場面でハンズフリー。
- 切替は orb の設定（`input_mode`）。保存時に聴取中なら voice.py を再起動して反映。
- 認識精度も底上げ：Whisper を base→small（GPUあれば cuda、無ければ CPU 約1.5秒）。語彙ヒントと併用。
