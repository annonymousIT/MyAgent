# ADR-0036 デスクトップ常駐 orb（presence）— 水の波紋・クリックで設定

- 状態: 採用（2026-06-11）。

## 課題
GUIレス（[ADR-0021]）を保ちつつ、「私、ここにいますよ」をさりげなく示し、設定（特に声）への入口が欲しい。
最初の実装は中心が拡縮＋明滅＋反射ハイライトで「気持ち悪い」とユーザー却下（2026-06-11）。

## 判断
- **中心の丸は固定**（動かさない・反射ハイライト無し）。動くのは周囲だけ。
- 周囲は**水に物を落とした時の波紋**＝中心から同心円のリングが広がりながら外縁で透明色に溶けて消える。
  定期的（≈1秒ごと）に新しい波紋を落とす。違和感のある脈動をやめ、静かな"佇まい"にする。
- 操作：**クリック=設定画面 / ドラッグ=移動 / 右クリック=終了**。
- 実装は **tkinter のみ（追加依存ゼロ）**。Windows は `-transparentcolor` で背景を透過し丸く浮かせる。
- 設定画面：音声ON/OFF・VOICEVOX話者・ピッチ/速度・声テスト・今月の予算。値は `settings.json` に保存し
  `speak.py` がターンごとに読む＝**再起動なしで即反映**（[settings.py]）。

## 影響
- `overlay.py`（波紋アニメ＋設定パネル）、`settings.py`（永続化）、`speak.py`（settings 連携・音声トグル）。
- 検証（2026-06-11）: 起動・波紋描画・設定保存→`speak._voice_cfg()` 反映を実機確認。

## Update（2026-06-11）: 上品リファイン＋配色テーマ
波紋版を更に上品に。中心の球を小さく（直径54px）、固いフチを消すため body 色を CHROMA から
立ち上げる**柔らかい光のにじみ**を追加、芯は同心円で中心ほど明るく＝“淡く光る球”（反射＝オフセット
白点ではない・ユーザー却下を踏襲）。波紋はゆっくり（≈1.4秒間隔）・細く。
**配色テーマ4種**（moonlight 月明かり=既定 / amethyst 紫水晶 / mist 霞 / ember 灯火）を `settings.json`
の `orb_theme` で選択、設定画面のドロップダウンから**保存で実行中 orb に即反映**。
