# ADR-0027 複数ステップ実行（ツール呼び出しをループ化）

- 状態: 採用（2026-06-11）。実機で発覚した「起動はするが配置しない」バグの根治。

## 課題
「ディスコード左、ムードル右で」のような指示で、アプリ起動まではするのにウィンドウ配置が実行されなかった。
原因は `core.run_turn` が **ツール実行を1ラウンドしか回さない**実装だったこと:
1ラウンド目で2アプリを起動 → 2手目の「配置(manage_window)」は2ラウンド目の tool_use になるが、
旧コードは2回目のAPI応答を**テキストとしてしか受け取らず tool_use を捨てて**いた。
結果「次に配置します」と言うだけで永久に配置されない。

## 判断
`run_turn` を **stop_reason が tool_use の間ループ**する素朴なエージェントループにする
（テキストで返してきたら終了）。これで「起動 → 配置」「配置 → 配置」など複数ステップが
1ターン内で完結する。暴走防止に `MAX_TOOL_ROUNDS=5` の上限を置き、上限到達時は
ツール無しで締めの一文だけ書かせる。空返答「（…）」はツール結果で埋める保険を維持。

## 影響
- core.py: 単発の `create→（tool）→final` を for ループに置換。max_tokens 300→400（複数tool_useの切れ対策）。
- 検証(2026-06-11, dry): 「ディスコードを左、ムードルを右に並べて」→ manage_window×2 を1ターンで発行。
  「ディスコード開いて左に寄せといて」→ launch_app→manage_window の2ラウンドが連続実行。
- 残る制約: 実配置はアクセシビリティ許可が前提（[ADR-0025]）。許可後にE2E検証。
