# ADR-0013 略語・口語の解釈（menu制約＋ファジー＋聞き返し）

- 状態: 採用（2026-06-11）

## 課題
「ばろ」（Valorant）「ディスコ」（Discord）「ようつべ」（YouTube）のような略語・口語を、どう正しい操作へ結びつけるか。

## 選択肢
- A. 網羅的な alias 辞書を人手で持つ
- B. 実行時 LLM のファジー解釈のみ
- C. セットアップ生成 alias ＋ 実行時ファジー（ハイブリッド）

## 判断
**C**。
- **セットアップ時**：LLM が各アプリ/サイトの呼び名リスト（略語込み）を生成し menu に載せる（決定的・高速）。[ADR-0012](0012-app-classification-llm.md) の生成と同じ。
- **実行時**：漏れた表現は menu 制約下で LLM が最近傍の操作へ寄せる。確信が無ければ聞き返す（[ADR-0014](0014-misspeak-handling.md) と共通）。

## 理由
- 頻出語は決定的に速く確実、ロングテールは LLM で吸収。
- **menu に閉じる**ので、知らない語でも勝手に誤爆しない。

## 影響
- 既存の menu 注入（システムプロンプトへ利用可能操作を同梱）の延長で実現。
- 聞き返しロジックは [ADR-0014](0014-misspeak-handling.md) と共通化。
