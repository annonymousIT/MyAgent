# ADR-0018 登録外でもPC内でできる範囲で最大限応える

- 状態: 採用（2026-06-11）。[ADR-0013](0013-abbreviation-handling.md) / [ADR-0014](0014-misspeak-handling.md) の「無いものは正直に断る」を“最後の手段”に降格する追補。

## 課題
「メール確認したい」→「用意がありません」で止まると使えない。登録済みの操作だけに閉じず、**PC内で実現可能なことは可能な限り叶えにいく**べき。

## 判断（振る舞いの3段階）
- **Tier1**：登録ツールがあればそれを使う（PWA優先・[ADR-0016](0016-site-vs-pwa-app.md)）。
- **Tier2**：登録外でも**PCで実現可能なら汎用手段で叶える**。情報系（天気・ニュース・「調べて」）→ 関連サイト or Web検索を開く。(Step3で)読み上げる。
- **Tier3**：そもそもPCで不可能なときだけ正直に断る。

**捏造防止は維持**（[ADR-0005相当]）：天気を想像で「晴れです」とは言わない。**実ソースを開いて本物を読む**。「知らないなら、知れる場所を開く」へ進化。

## 実装
- 汎用ツール **`open_url(url)` / `web_search(query)`** を1つ追加し、長尾を吸収（サイトを無限登録しなくてよい＝引き算思想）。
- Tier2 デフォルト＝**Web検索**。よく使うものは `sites` 登録で上書き（調整可）。

## 安全境界
- **汎用化するのは「ブラウザで開く」だけ**（可逆・低リスク・無確認）。
- アプリ起動／システム操作の権限と汎用化の可否は [ADR-0019](0019-permission-model.md) で別途規定（任意コード実行は禁止）。

## 影響
- `open_url` / `web_search` の新ツール実装（次の実装タスク）。
- persona / menu に「無ければ調べる・開く」方針を追記。
