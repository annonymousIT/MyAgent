# ADR-0042 1ターン単価の構造分析 — rephrase撲滅・5分TTL・プレフィックス圧縮

- 状態: 採用（2026-06-12）。[ADR-0033](0033-cost-meter-and-cache-threshold.md) / [ADR-0039](0039-monthly-cost-cap.md) の続き。「1ムーブ0.3円以下（1000会話で月300円）」を目標に。

## 課題
実測平均が **¥0.629/ターン（月¥629）** で目標¥0.30の倍。`costs.jsonl` は yen と calls しか持たず**何が高いのか不明**。当初「冷キャッシュ（間が空くとTTL切れで安定部4373tokを書き直す）が主犯」と仮説したが、間隔分布は32/39が5分以内＝大半は温のはずで、矛盾していた。

## 判断（測ってから決める）
- **計装**：`_acc` に cw/cr/in/out を呼び出し単位で記録（`cost_calls.jsonl`、タグ付き loop/rephrase/force_save）。これで初めて内訳が見えた。
- **発見1 — rephrase の丸損**：ツールターンの4〜5割で `call2 が out=2（無言）→ call3 rephrase` が発生。モデルは**1回目で既に narration 済み**（call1 out=100〜250）なのに、`_finish` が「もう喋った内容」を生成するため3回目のAPI（cr4534＋in≈850 ≈¥0.24）を丸々叩いていた。声モードでは発声済みなので**純粋な浪費**。
  → **修正**：`_finish` で `streamed["text"]` が非空なら（＝既に喋った）それを返答に採用し rephrase を呼ばない。二度喋りも同時防止。
- **発見2 — TTLは5分が正**：cw（書込）が全ターンで発生（ツール往復の共有尾部 ~700tok が自動キャッシュ拡張書込・読まれず丸損）。1時間TTLは書込を1.25→2.0倍にするため、この毎ターン書込を倍課金していた。間隔分布と合わせ計算すると**5分TTLの方が安い**（毎ターン書込税 > 稀なギャップ冷書込）。→ 既定を5分に戻した（`MYAGENT_CACHE_TTL`）。
- **検証して捨てた案 — 揮発の位置移動**：cw が揮発ブロックの位置由来かを2方式直接実測 → 両方 cw=831 で**効果なし**（cw は位置でなく共有尾部が原因）。推測で実装せず実測で棄却。
- **プレフィックス圧縮（中）**：TOOL_DEFS の大半は JSON 構造で圧縮不可。static_menu の冗長英語を圧縮（人格・全ルールは保持）。5099→4785tok（後に窓機能で4973へ、圧縮前より下）。効果は小（温時0.1x）。

## 影響（実測）
- 雑談（calls=1）¥0.25 = 元から目標達成。ツール（calls=2）¥0.85→**¥0.62**（rephrase撲滅）。混在平均見込み **¥0.35〜0.40（月¥350-400）**、当初¥629から約4割減。
- 残る構造的下限：ツール往復は最低2回API＝各回4534tokプレフィックス読み直し。これ以上は**コードでの意図ルーティング（LLM経由回数を減らす高速パス）**が本命だが、汎用性とのトレードオフを残し別途検討。
- `core.py`: `_finish` rephrase短絡 / `_CACHE_TTL` / cw倍率 / 計装。`costreport.py`・`cost_calls.jsonl` 追加。
