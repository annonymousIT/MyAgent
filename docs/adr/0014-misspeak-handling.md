# ADR-0014 言い間違い・誤認識の吸収（可逆性段階化＋エコー）

- 状態: 採用（2026-06-11）

## 課題
言い間違いをどう扱うか。発生源は 2 つ：
- (a) 音声認識ミス（Step2 の Whisper が聞き違える）
- (b) 本人の言い間違い・自己訂正（「ディスコ…じゃなくて Slack」「やっぱりさっきのやめて」）

## 選択肢
- A. 毎回確認を取る
- B. 何もしない（誤っても実行）
- C. 可逆性で段階化＋エコー確認＋短期記憶

## 判断
**C**。
- **可逆性で段階化**：サイト/アプリ起動など可逆な操作は即実行して結果を報告。危険操作（スリープ・再起動等）は実行前に確認（既存踏襲）。
- **自己訂正**：1 発話内の「A じゃなくて B」は LLM が自然に処理。
- **ターンまたぎの訂正**（「さっきのやめて」）は短期会話履歴が必要 → Step5（記憶）で対応。
- **不確実なら聞き返す**（[ADR-0013](0013-abbreviation-handling.md) と共通）。

## 理由
- 可逆な操作にいちいち確認すると UX が死ぬ。エコー報告で即訂正でき、**確認は危険操作だけに絞れば安全と快適を両立**。

## 影響
- エコー（返答での操作明示）は実装済み。
- ターンまたぎ訂正のための短期会話履歴は Step5 として別途。
- confidence-gate（聞き返し）は [ADR-0013](0013-abbreviation-handling.md) と共通実装。
