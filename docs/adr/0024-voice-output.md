# ADR-0024 音声出力（読み上げ）— VOICEVOX 優先・OS標準フォールバック

- 状態: 採用（2026-06-11）。[ADR-0021](0021-delivery-model.md) の「伝える」を音声まで全う（Step3）。

## 課題
返答を「画面に出す」だけでなく**声で届ける**（世話焼き人格・ハンズフリーの土台）。
ただし高品質な日本語TTS（VOICEVOX）は**ローカルエンジンの常駐が前提**で、ハード依存にすると
「エンジンを入れていないと一切喋らない／起動が重い」ことになる。

## 判断（VOICEVOX 優先・無ければ OS標準にフォールバック）
- `speak.py` の `speak(text)` は **まず VOICEVOX（`localhost:50021`）を試す → 失敗したら即 OS標準**（Mac `say` / Win SAPI）。
  - 接続拒否は一瞬で返る（実測 6ms）ので、未起動でもブロックしない。
  - ユーザーが VOICEVOX を起動していれば**無依存のまま自動で高品質音声に昇格**。
  - 環境変数 `VOICEVOX_URL` / `VOICEVOX_SPEAKER`（既定: ずんだもん `3`）で差し替え可能。
- **発声は「端」で行う**（`web.py` / `agent.py`）。`core.py` は UI/出力非依存を維持。
- Web UI（開発用）は既定で**無音のまま**。「読み上げ」**トグル（既定OFF）** を追加し、ON のときだけ発声。
  - 発声は**別スレッド（block=False）**で行い、返答表示を待たせない。

## 影響
- `speak.py`: VOICEVOX クライアント（audio_query→synthesis→afplay/SoundPlayer）＋ `block` 引数を追加。`speak(text)` の I/F は不変なので `agent.py`(CLI) は無改修。
- `web.py`: 「読み上げ」チェックボックス＋`read_aloud` フラグ＋ハンドラで非同期発声。
- 検証（2026-06-11）: VOICEVOX未起動→`say`フォールバックを実発声で確認。サーバ経由E2E（「今日の天気どう茨木」読み上げON）成功・発声スレッドはサーバを巻き込まず安全。

## Update（2026-06-11）: sayの記号読み修正（VOICEVOX未導入時の品質）
VOICEVOX未導入で say にフォールバックする際、①英語ボイスが既定だと日本語を記号読み（「…」→"dot dot dot"等）し、
②返答の顔文字(^^;)・三点リーダ(…)・絵文字をそのまま読み上げて聞き苦しかった。対策:
- `_os_speak` を **日本語ボイス（既定 Kyoko / env SAY_VOICE）** で発声。無ければ素の say にフォールバック。
- `clean_for_speech()` で読み上げ前に 顔文字(^起点に限定し 。、！？ は保持)・三点リーダ(→読点)・絵文字・Markdown記号を除去。
  テキスト表示はそのまま（記号は人格の味）、音声だけ綺麗にする。VOICEVOX 経路にも同じ整形を適用。
- 実機: say -v Kyoko で日本語が自然に、記号読みが解消。
